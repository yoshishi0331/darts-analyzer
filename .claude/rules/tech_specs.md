# Darts Analyzer Technical Specifications

## 解析フロー
ホーム →「解析を始める」→ セッション設定画面 →「動画を選ぶ」→ 動画選択
→ release（リリース安定ON時のみ）→ landing（グルーピング/狙い精度ON時のみ）→ compare（結果）
※segmentステップ・targetステップは完全廃止。

## セッション設定画面
- **狙い**: ブル/20/19/18/17/16/15（横並びグリッド、1つ選択必須）
- **測定項目**: グルーピング / リリース安定 / 狙い精度（全部ONがデフォルト）
- **バリデーション**: 最低1項目ON必須。狙い精度ON時は狙い選択必須。
※ 選択状態はセッション中のみ保持（AsyncStorage永続化不要）

## UI方針
- **release**: 「ダーツが指から離れた瞬間をタップしてください」
- **landing**: 「ダーツが刺さった位置をタップしてください」
- 共通: 矢印キー（十字配置、1タップ正規化座標0.005移動）、3投入力必須。
- **compare**: ResearchCanvas表示。測定指標のみ表示。フィードバックエリア表示。

## スコア計算
- **セッション単体**: 測定した指標のみで再計算（3指標: グルーピング0.4 + リリース0.4 + 狙い精度0.2 / 2指標: 各0.5 / 1指標: そのまま）。
- **ホーム画面**: 指標ごとに直近N件の平均を使用。データなしは「--」表示。
- **グルーピングアルゴリズム**:
  ① 3点間の距離を3通り計算。② 中央値をベースに。③ 100 - (中央値 × 2.8) を0-100クランプ。
  ④ 最大距離 / 中央値 > 3 (仮) ならスコア0.85倍。

## targetPoint 座標マッピング
正規化座標系（左上0,0・右下1,1・中心0.5,0.5）基準。
- ブル(0.50, 0.50) / 20(0.50, 0.29) / 19(0.44, 0.70) / 18(0.62, 0.33) / 17(0.57, 0.70) / 16(0.33, 0.62) / 15(0.67, 0.62)

## 腕の角度測定（90度計測機能）
- **位置づけ**: スコアリングに影響させず、原因特定サポートの参考指標とする。
- **定義**: L字=90°、テイクバック<90°、リリース理想90〜95°。
- **タップフロー**: 肩→肘→手首の順（各フェーズでプレビュー→確定）。
- **角度計算**: 肘関節角。（肘→肩）ベクトルと（肘→手首）ベクトルのなす角。前腕と垂直線のなす角は使用しない。
- **フィードバック閾値**: ≤95°(良い) / 96〜105°(やや遅め) / >105°(遅い)

## フィードバックロジック
- スコアリングは着弾位置ベース。腕の角度は未測定の場合スキップ。
- グリップ・矢角への言及は直近3セッション以上継続した場合のみ（イップス防止のため）。
- ①着弾垂れ＋90度超え(単発) / ②着弾垂れ＋90度以内 / ③着弾垂れ＋90度超え(3回継続) / ④着弾正常＋90度超え / ⑤着弾高め / ⑥左右ブレ / ⑦グルーピング良好＋着弾ズレ / ⑧グルーピングバラバラ / ⑨1本だけ極端ズレ。

## 音声入力 Phase 1（プロトタイプ評価）

### 目的
音声認識の「実戦投入が可能か」を判断するためのテスト画面。
ライブラリ: `@react-native-voice/voice`（`expo-dev-client` 必須）

### 成功判定基準
- **精度 70%以上** → Phase 2へ進む（UI統合・スコア保存実装）
- **精度 50〜70%** → カスタム辞書の検討、または発話パターンの限定を検討
- **精度 50%未満** → ライブラリ変更、または Bare Workflow への移行を検討

### テスト項目（実機で発話して確認する語）
| 発話 | 期待する認識結果 | カテゴリ |
|---|---|---|
| 「ブル」 | ブル | 狙い |
| 「にじゅう」「20」 | 20 / 二十 | 狙い |
| 「にじゅうにあ」「20ニア」 | 20ニア / 20near | 狙い+位置 |
| 「じゅうく」「19」 | 19 / 十九 | 狙い |
| 「とりぷる」「トリプル」 | トリプル | 位置 |
| 「しんぐる」「シングル」 | シングル | 位置 |
| 「みす」「ミス」 | ミス / 外れ | 結果 |

### 画面仕様（QuickRecordScreen）- キュー方式（v2）
- タブ名: 「クイック記録」、アイコン: `mic-outline`
- **音声キュー方式**: 発話のたびに1投目→2投目→3投目のスロットへ数字が自動入力される
- **スロット構成**: 数字表示（タップで修正パネル） ＋ [Near][Mid][Long] ボタン
- **未確定保持**: 判定ボタンを押すまでデータ保存しない（その場に留める）
- **一括確定**: 3投すべてに数字＋判定が揃った時点で「保存して次のラウンドへ」ボタン活性化
- **クリア**: 「やり直し」ボタンで現ラウンドのスロットをすべてリセット
- **dartsNumericMapper**: 音声誤認識を補正する専用辞書（二次/二重/虹→20、自由→10 等）
- 連続認識: 結果取得後・無音タイムアウト後は自動で `Voice.start` を再呼び出し
